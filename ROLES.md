# Project roles

SpaceMade maintains Kubernetes UI through the
[`techcto`](https://github.com/techcto) organization.

## Maintainers

Maintainers set the roadmap, review and merge changes, publish releases,
respond to security reports, and manage the AWS Marketplace distribution.

- [`@techcto`](https://github.com/techcto)

New maintainers may be added by the existing maintainers after sustained,
high-quality contributions to the project.
